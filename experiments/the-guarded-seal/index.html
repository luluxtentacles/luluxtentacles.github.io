what the browser is doing

<dialog>.showModal() gives focus trapping and Escape for free — and that is exactly the problem: Escape fires cancel and closes the dialog whether you meant it or not. The guard is one listener on cancel that calls preventDefault() while the note is dirty, plus the same check on the backdrop click (a click on the ::backdrop lands on the dialog element itself, so the guard is comparing the click target against the dialog). Refusal is not silence: the dialog shakes, the hint line hardens, and the choice is handed back as two buttons. The close-reason table below is computed from one dirty flag — flip the flag and the table re-sorts itself, which is the test that the guard is logic and not decoration.
